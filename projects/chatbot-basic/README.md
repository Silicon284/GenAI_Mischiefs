# Chatbot Basic

A basic chatbot implementation using GenAI technologies.

## Description

This project demonstrates fundamental chatbot capabilities including:
- Basic conversation handling
- Intent recognition
- Response generation
- Context management

## Getting Started

```bash
npm install
npm start
```

## Features

- Simple conversation flow
- Configurable responses
- Basic NLP integration
- Extensible architecture

## Usage

Run the chatbot and interact through the command line interface.
